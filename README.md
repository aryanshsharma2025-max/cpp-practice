## 🎯 Key Object-Oriented Programming Concepts (`17_OOP`)

The OOP section contains focused exercises exploring modern C++ class mechanics:
- **Constructors & Destructors**: Default, parameterized, and copy constructors with deterministic cleanup.
- **Access Specifiers**: Proper encapsulation using `private`, `protected`, and `public` boundaries.
- **Inheritance**: Single, multiple, and hierarchical inheritance hierarchies.
- **Polymorphism**: Compile-time function overloading and runtime virtual method resolution.

## 🛠️ Compilation & Local Execution

All programs are written to comply with standard modern C++ (`C++14` / `C++17`).

### Single File Compilation
Using GCC / MinGW `g++`:

```bash
# Compile with standard warnings
g++ -std=c++17 -Wall -Wextra 17_OOP/01_Basics/001_class_object.cpp -o app

# Run binary
./app
```
